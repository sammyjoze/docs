Chatr's appearance settings let you match the widget to your brand — from the floating button shape to the bot avatar and primary color. Every option is configured in the Chatr dashboard at [chatrai.app](https://chatrai.app), and changes roll out instantly to your live widget.

## Avatar & Identity

Choose how your bot presents itself visually to visitors.

- **Preset** — Pick from a library of built-in avatars that ship with Chatr.
- **Upload** — Upload your own JPG or PNG image to use as the bot's avatar.
- **AI Generate** — Generate a unique, custom avatar using Chatr's built-in AI image tool.

**Launcher shape** controls the style of the floating chat button and the in-chat bot avatar. Choose from:

- **Circle** — The default rounded style.
- **Rounded square (tile)** — A softer square shape that suits more geometric brand identities.

## Name & Description

Give your bot a voice and identity that fits your brand.

- **Bot Name** — Up to 20 characters. Displayed prominently in the widget header so visitors know who they're talking to.
- **Bot Description** — Up to 25 characters. Shown beneath the bot name on desktop, used as the text in your dashboard banner, and injected into the AI's brand context prompt to guide its responses.

<Tip>
  Your Bot Description is also injected into the AI's brand context prompt, so make it specific — e.g. "AI assistant for Acme SaaS" rather than just "AI assistant".
</Tip>

## Colors & Welcome Message

Set the visual tone and the first thing visitors read when they open the widget.

- **Primary Color** — Sets the widget's accent color across buttons and highlights. Click the color swatch to open the color picker and enter a hex value or choose visually.
- **Welcome Message** — The first message visitors see when the chat opens. Write 2–3 sentences that set expectations and invite engagement. Supports basic markdown formatting:
  - Bold text: `**your text**`
  - Bullet points: `- item`

## Dashboard Banner

Toggle the optional home banner on to display an announcement or greeting at the top of the chat widget header. Use it to highlight a promotion, a new feature, or a seasonal message — without changing your welcome message copy.

## Compose Placeholder

Set the hint text shown inside the message input box before a visitor starts typing. A clear, inviting placeholder like "Ask me anything..." or "How can I help you today?" encourages visitors to engage.

<Note>
  Changes take effect immediately for new conversations. Reload the preview to see updates.
</Note>
